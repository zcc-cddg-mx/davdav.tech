# davdav.tech Development Recommendations

## Version 1.0

## Purpose

This document provides strategic, technical, branding, and content recommendations for the successful development and long-term growth of davdav.tech.

---

# Strategic Recommendations

## Focus on Personal Brand Before Portfolio

The website should primarily sell the professional brand of Carlos David Duarte rather than acting as a traditional developer portfolio.

Target positioning:

- Senior Software Engineer
- Technical Lead
- Application Owner
- Cloud Professional
- Future Solution Architect

---

## Build for the Next Role

The website should reflect not only current responsibilities but also future career goals.

Design decisions, content, imagery, and messaging should reinforce a transition toward:

- Solution Architecture
- Cloud Architecture
- Technical Leadership

---

# Technical Recommendations

## Recommended Stack

- Next.js
- TypeScript
- Tailwind CSS
- MDX
- Vercel or compatible hosting

## Performance Goals

- Lighthouse score above 90
- Mobile-first design
- Fast image loading
- Strong SEO foundation

## Security

- HTTPS only
- CAPTCHA on contact forms
- Email obfuscation when possible
- Security headers
