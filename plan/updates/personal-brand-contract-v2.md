# Personal Brand Contract - davdav.tech

## Version 2.0

### Visual Identity & Media Assets

#### Purpose
Professional photography and AI-assisted branded imagery are strategic assets of the davdav.tech platform.

The visual identity shall reinforce:
- Senior Software Engineer
- Technical Lead
- Application Owner
- Cloud & Solution Architecture

### Personal Brand Consistency Rule
No page, image, article, or feature shall position the owner solely as a Java Developer.

All assets must reinforce the progression:
Software Engineer → Technical Lead → Application Owner → Cloud Professional → Solution Architect
